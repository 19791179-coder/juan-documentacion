# 📚 Documentación del Sistema de Asistencias · Módulo 3.4

> *"La buena documentación no se escribe, se diseña."*

---

## 📋 Descripción del Proyecto

Este repositorio contiene la documentación completa del **Sistema de Asistencias** desarrollado para el **Instituto Nacional de Osicala (INO)** como parte del **Módulo 3.4 · Documentación de Sistemas** del Bachillerato Técnico en Desarrollo de Software.

El proyecto documenta el flujo completo de registro de asistencia, generación de reportes y administración de usuarios, siguiendo estándares profesionales de documentación técnica.

---

## 📂 Estructura de Archivos

| Archivo | Descripción |
|---------|-------------|
| 📄 `etapa_decidir_1_2_3_4.pdf` | Documento principal con la investigación de normas, análisis de manuales y benchmarking |
| 📄 `Manual_Usuario_Sistema_Aristencia_PROFESIONAL_verificado.docx` | Manual de usuario profesional verificado del sistema |
| 📊 `presentacion para mañana.pptx` | Presentación para la exposición del proyecto |
| 📖 `README.md` | Este archivo, con la documentación del repositorio |

---

## 📑 Contenido del Proyecto

### 1. Investigación de Normas ✅
- Análisis de estándares de documentación
- Normativas aplicables al desarrollo de software

### 2. Análisis de Manuales ✅
- Estudio de manuales de usuario existentes
- Identificación de mejores prácticas

### 3. Benchmarking ✅
- Comparativa con sistemas similares
- Análisis de competencia

### 4. Matriz de Diseño ✅
- Estructura del manual técnico
- Definición de secciones y contenido

### 5. Borrador del Manual ✅
- Versión preliminar del manual de usuario
- Revisión y correcciones
